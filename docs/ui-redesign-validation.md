## 布局变动与保留范围

- 用户端改为顶部品牌/操作栏、横向工作区导航、独立页面标题和宽内容区；桌面导航吸顶。移动端保留全量抽屉导航，支持焦点进入、Tab 循环、Escape 关闭与焦点返回，关闭的抽屉不可被键盘误入。
- 管理后台使用页头下方的独立导航面板，保留所有原业务分组及个人菜单；折叠、展开、版本更新与回退入口仍在。
- 控制台快捷操作移到总览旁，趋势图为主、模型分布为辅，使用记录占独立整行；账户统计、平台额度、全部图表数据与控制项保留。
- 登录等认证页面采用品牌/接入说明与原表单分栏；手机回到单列。原表单插槽、OAuth、邀请码、验证、协议和帮助不删减。
- 列表页把原操作与筛选组织成工作台，表格仍可内部滚动。360px 下端点和分组按钮允许换行，地址、复制、测速及分组选择均保留。
- 默认首页改为中央品牌介绍与横向接入步骤；自定义 HTML、URL 及 compact 首页的优先级不变。

本轮没有改后端、API、路由、store、类型、功能开关规则、计费/鉴权/调度、数据库、依赖锁文件或 LICENSE。菜单构造及过滤规则与基线逐字一致；只改变其呈现位置。

## 推广与主题

移除默认首页、密钥用量页、管理员用户菜单中的静态仓库推广链接。最新用户要求替代了第一轮“界面保留 GitHub 仓库入口”的决定。保留管理员配置的文档/菜单/公告、支付配置帮助、OAuth 配置、协议、更新和回退能力；它们属于业务或运维操作。许可证和源码来源记录保留。

主题规则：保存的 `theme=light/dark` 优先；没有手动选择时跟随系统，无法取得系统偏好时白色。监听系统实时变化及跨标签偏好更新；所有共用主题控件提供「自动」入口，恢复跟随系统。语言继续使用 `sub2api_locale`，标题及新增文案均有中英文。

## 验证结果

浏览器为本机 Chrome/Playwright，未声称覆盖所有浏览器：

- 用户端 11 页、公开页 7 页 × 中文/英文 × 日间/夜间 × 390/768/1440px，**216 组**无整页溢出、页面脚本异常、扫描到的裸翻译键或最终 API 错误。
- 管理列表 5 页 × 同一组合，**60 组**无溢出/脚本异常；系统设置 9 页签 × 双语/日夜 × 390/1440px，**72 组**无溢出/脚本异常。管理端使用响应 fixture，拒绝管理员写请求，不等同于所有管理操作的端到端验收。
- 加测 360/1024/1920px 的总览、密钥和个人资料，9 组通过；360px 初测的英文端点/分组溢出修复后重跑通过。
- 浏览器真实登录、密钥创建/编辑/启停/删除、接入弹窗、搜索/清除、列设置、手机菜单、语言切换、标题、刷新后偏好均通过。
- 开关开启/关闭与批量图片访问 fixture 通过；支付、订单、返佣、渠道、批量图片及自定义菜单继续按原条件显示。
- 系统浅色首次访问、实时切深色、手动浅色覆盖系统且刷新保留、恢复自动，以及抽屉键盘行为通过浏览器验证；缺失系统能力及跨标签同步另有行为单测。
